## Create a project

Are you looking for a way to get a quick glance into the different elements of your project? Then, projects are just what you need!

They are a fantastic way to create small studies that will help you understand everything that is involved in your project.

How to Create a Project?

To create your project, you have two options:

You can either click on "Create a new Project" on the homepage, or

Click on "Create" in the Project tab.

What all information is required to add inorder to create a project?

To create a project, remember to include the following details:

- Project Name: Give a name to your project, similar to how you name your files.

- Requested by: This field will be autofilled with the user who requested the project.

- Due/Complete date: Indicate the date by which the project needs to be completed or the date on which it should be completed.

- Project Brief: Provide a brief description of what the project is about.

- Program: It specifies under which Program your Project should fall into. By default, all the projects will be categorised under General Program.

- Customer point of contact (email address): Provide the email address of the primary point of contact for the project. This will allow you to reach out to them directly in case of any issues.

By following these simple steps, you'll be able to create a project that is both effective and efficient.

So, let's get started! Just click on the "Add project" button and begin your project today.

Are you wondering what the list on the left-hand side of the page is for?

The list displays project types that can be imported from surveys, created under taxonomy, or be a default project.

To create or manage project types under taxonomy, navigate to Settings >> Hub Settings >> Taxonomy.

This feature enables you to customize your projects according to your needs and preferences.
