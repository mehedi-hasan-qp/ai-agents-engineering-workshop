## Matrix Mobile Rendering

Mobile View (ON): When viewed on mobile devices, Matrix Tables often require respondents to scroll to see the full question. The Mobile Friendly option formats Matrix statements into a drop-down format so they can all fit on one screen.

We recommend enabling the Mobile Friendly setting for all Matrix Table questions.

Scrollable view (OFF) To see the scrollable view of the Matrix question, turn the Mobile Friendly setting off in the question settings panel. With this setting turned off, any part of the question that extends beyond the width of the mobile screen will require scrolling to view.

We do not recommend using Scrollable Format.

Where can I make the setting?

This function is available only for Multipoint scales, Multi-select multi-point scales and Spreadsheet question types.

You can go to: Matrix question >> Settings >> Mobile Rendering
