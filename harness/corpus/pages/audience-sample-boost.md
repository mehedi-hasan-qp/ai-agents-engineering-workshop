## Project Push (Sample Boost)

What is Project Push?

Project Push , also known as Sample Boost , lets you increase traffic to a live Audience project without closing or relaunching it.

When a project is collecting responses slower than expected, you can create an additional vendor-side launch for the remaining responses. This helps increase respondent traffic while keeping all responses and reporting under one Audience project.

The original project remains active, and the Audience platform manages all associated vendor projects in the background.

When should I use Project Push?

Use Project Push when:

- Your project is progressing slowly.

- The project is not collecting responses quickly enough.

- You want to increase respondent traffic without creating a new Audience project.

- You want to complete the project sooner while keeping the same project settings.

How do I push a project?

To push an Audience project:

- Go to the Projects page.

- Hover over the project you want to boost.

- Click Push Project .

- Choose one of the available options: Push at Same CPI or Push at Higher CPI .

- Review the push details and confirm.

The platform creates an additional vendor project for the remaining responses while keeping the existing Audience project active.

What push options are available?

You can choose from the following options:

- Push at Same CPI – Launches another vendor project using the current CPI and the same project settings. This option is available for the first two pushes on a project.

- Push at Higher CPI – Launches another vendor project using a higher CPI to help increase respondent traffic. The new CPI must be at least 10% higher than the project's current CPI.

For example, if the current CPI is $2.00, the minimum allowed CPI for a higher-CPI push is $2.20.

What happens after I push a project?

After a project is pushed:

- A new vendor project is created using the same targeting and qualifications.

- Only the remaining required responses are requested.

- Existing vendor projects continue collecting responses.

- Responses from all vendor projects are automatically combined in the same Audience project.

- You continue managing one Audience project while the platform tracks all vendor launches in the background.

What happens when I close the Audience project?

Closing the Audience project automatically closes all associated vendor projects.

No additional action is required.

Can I reconcile responses after pushing a project?

Yes. The Audience platform tracks the vendor project associated with each response.

This allows reconciliation requests to be processed accurately, even when responses come from different vendor projects.

Why can I no longer push at the same CPI?

The Push at Same CPI option is available only for the first two pushes on a project.

After the first two pushes, you must increase the CPI by at least 10% to continue boosting the project.

Does pushing create another Audience project?

No. Only one Audience project exists.

The platform creates additional vendor projects in the background while keeping all responses, reporting, and management under the original Audience project.

Will my project settings change after a push?

No. The new vendor project uses the same targeting, qualifications, quotas, survey settings, and other project configurations.

The only change is the CPI when you select Push at Higher CPI .

Will previous vendor projects stop collecting responses?

No. All associated vendor projects remain active until the Audience project is closed.

Can I see all vendor projects created through pushes?

The Audience platform automatically tracks all vendor projects associated with your Audience project.

These vendor projects are managed internally, so you can work with one Audience project while the platform handles the vendor-side launches.
