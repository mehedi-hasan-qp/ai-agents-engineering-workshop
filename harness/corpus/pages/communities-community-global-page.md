## Community Global Page

To edit the Global Page:

Go to: Community >> Content >> Global

What options can I see on Global Pages?

- Footer : Community owner can set the footer text under this link.

- Customize Theme : Community Owner can set design pattern using the stylesheet.

- Customize System : Community Owner can change the message text as per requirement.
