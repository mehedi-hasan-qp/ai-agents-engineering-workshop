## Projects Details

This page displays the list of all the projects created till date, irrespective of the place from where they were created.

What are these cards?

These cards are nothing but the overview of each project.
Basically, inorder to view the projects, there are 2 ways -

- Grid View

- List View

Can you please explain the table in the Grid View

Sure! so, each card that you see has a similar characterisitcs as below -

- Project Name

- Project Introduction/Description

- Date Created: i.e the date of creation of the project

- Program: This informs under which Program the Project is created. Program can be added from Settings >> Taxonomy >> Programs

- Type: This is the Project Type that is created from Settings >> Taxonomy >> Projects

- Owner: who is the owner of the project

- Metrics: These are the key indicators which defines the success of the project. These can be further set from Settings >> Project Management >> Metrics

- Move to Program or Delete Project: Move Program allows you to move the program of the project and Deletes allow you to delete the project altogether.

What are the other components on this page?

- Creation of Projects directly from the Projects page via Create Button.

- Searching the projects via Project name or description.

- Pagination- displays 50 projects per page.

- List View or Grid View switches.

- Restoration of Projects, if they were deleted.

The Gear Icon is only displayed in the List View. It provides options to the user, if they would like to see the projects in the basic view that is all the details mentioned above, or to see only the Key Metrics of that Projects or the Program Metrics.
