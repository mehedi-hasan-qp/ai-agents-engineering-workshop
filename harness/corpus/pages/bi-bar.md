## Bar Graph for your widget

What is Bar Graph?

A bar graph is a chart or graph that presents categorical data with rectangular bars with heights or lengths proportional to the values that they represent.

How to add a Bar chart?

Go to: Login » Select dashboard » Add widget » Question based or continue using this survey » Select question or part of a question » Select the Bar graph type » Add Widget

Click to download video

Step 1: Select a question

Step 2: Give a name to widget >> Select Pie Chart type >> Add Widget

Settings - Chart Elements

You can customize the chart elements such as enable or disable legends , display Axis Titles , highlight highest proportion in the chart, display data labels inside or outside the chart and customize Label Width

Click on options and settings of the widget:

Once the general setting are shown, scroll down to access chart elements.
