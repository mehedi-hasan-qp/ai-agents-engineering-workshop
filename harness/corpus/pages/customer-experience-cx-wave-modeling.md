## CX - Wave Modeling

Wave Modeling helps to import and save transactions on a monthly or quarterly basis.
It helps majorly in grouping the data for Reporting.

How do you add a Wave?

To add a Wave , you can got to:
Customer Experience >> Business Data >> Wave Modeling

- Click on 'Add Wave'.

- Enter Wave details-

- Wave Name- Enter a name to identify the wave.

- Wave Code- Enter a unique code that defines the wave.

- Type- Can be Monthly or Quarterly

- Select Month/Quarter- Select the month/quarter from the drop-down.

- Year- Select the year from the drop-down.

- Click on Submit.
