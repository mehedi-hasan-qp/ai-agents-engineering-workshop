## Communities: Mobile Application FAQ

The QuestionPro Communities mobile application allows you to better engage with customers giving real-time community insights. With push notification and geo-location surveys, it easier for members to stay active in your community and share experiences on the go; by participating in activities like Discussions, Polls, Surveys and many more...helping you get the pulse of your community, enhance your relationships, know your customer’s needs, identify key drivers and make informed business decisions.

QuestionPro Communities app powers you with a convenient way to engage with your community on the go, it allows engaging with your community like never before and has simpler and easy to use interface.
Application is available for Android and iOS-based devices.

Supported device or OS?

The application is developed to support all the mobile devices running on the Android OS version above 4.1.
For devices running on iOS all the mobile devices above OS version 8.0. The application is developed to work on both iPhone and iPad.

How do I enable mobile application for my community, what is the Access Code?

It is very easy to allow your community members to access the community using the mobile application. However, members would need added credentials for logging in using mobile application i.e. Access Code. This Access Code is used to identify the community user belongs.

If you enable mobile application, also add Access Code and share the same with your community members.

Can I send important messages and announcements on mobile application?

Yes, from the admin panel you will be able to draft the message and share it with your community members on the mobile application. You can do this in the Mobile module under Modules tabs.

You also have an option to choose whether to notify the members of this notification by sending Push Notification on their devices.

Is it possible to update the profile details from the community app?

No, currently a member cannot update the profile using mobile application.

Will members be able to contribute to the live discussions?

Member can join contribute to live discussions that are active from the application, under the collaborate tab after logging in.
