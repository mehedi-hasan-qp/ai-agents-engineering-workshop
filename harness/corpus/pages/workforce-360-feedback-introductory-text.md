## 360 Feedback - Introductory Text

360 feedback introductory text allows survey admin to show introduction message to the reviewers before they start reviewing their employees. Survey admin can define the introduction text using this feature.

How can I enable/edit introduction text?

To enable/edit introduction text, go to:

Login >> Workforce >> 360 feedback survey

- Click on Settings .

- Enable/edit introduction text and click on Save
