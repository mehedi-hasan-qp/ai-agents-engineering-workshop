## Landing Page

What will a user see when they signup on InsightsHub?

Welcome to InsightsHub! Our platform offers an easy and efficient way for you to manage your projects, all in one place.

Once you sign up, you will land on our user-friendly landing page, where you can create projects.

With three options to choose from, we're confident you'll find the perfect one for your needs:

- Create a new project: This option is perfect for those who want to start from scratch and create a brand new project.

- Sync with QuestionPro Surveys: If you're already using QuestionPro and have surveys in it, this option is ideal for you. Import all of your survey data at once and get started right away.

- Import external data: If you'd like to import external data via OneDrive, G-Drive, SharePoint, we've got you covered. Our platform is designed to make it easy for you to access all of your data in one place.
