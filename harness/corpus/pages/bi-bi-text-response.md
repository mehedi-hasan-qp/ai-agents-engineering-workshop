## Text Response

1. Introduction

The Text Response Widget allows users to view and analyze verbatim responses to open-ended questions in a survey.

It enables deeper insights by offering keyword-based filtering and sentiment tagging, making it easier to detect customer intent and tone.

1. Core Functionality

- View all verbatim responses for a selected open-ended question.

- Search for specific keywords to filter relevant responses.

- Enable automated sentiment detection to classify each response as Positive, Neutral, or Negative.

1. Step By Step Guide

- Step 1: Create dashboard – To create text response widget create a new dashboard or in an exsisting go to Step 6.

- Step 2: Select blank dashboard – Choose a blank dashboard layout as the starting point for adding your text response widget or in an exsisting go to Step 6.

- Step 3: Add widget – Click on “Add Widget” to begin inserting visual elements, into your dashboard

- Step 4: Select your widget – Choose the text response widget and link it to a specific open-ended survey question to visualize verbatim from each respondent in the survey.

- Step 5: Select survey and survey question – Select the relevant survey and then choose a text-based (open-ended) question. The text response widget supports only text question types to display respondent verbatim.

- Step 6: Select text response widget – This widget is designed to display all verbatim responses associated with a selected open-ended survey question. It provides options to search specific keywords and optionally enable sentiment tagging for each response.

- Step 7: Text response widget added to dashboard – Once selected, the text response widget will be added to your dashboard, displaying all text responses linked to the chosen open-ended question

- Step 8: Search keywords in text response – Use the search bar to filter and display only those text responses that contain specific keywords of interest.

- Step 9: Highlight Sentiment – Click the three-dot menu (⋮) on the widget, go to Settings > Analytics, and enable "Highlight Sentiment" to display detected sentiment for each response.

- Step 10: Final text response widget – The widget is now fully configured and displays all open-ended responses, along with keyword filters and optional sentiment highlights for easier analysis.

Glossary

un ordered list

- Verbatim Response : A respondent’s exact written answer to an open-ended survey question.

- Keyword Search : A search tool to filter and display responses that contain specific keywords or phrases.

- Sentiment Detection : An automated system that classifies each response as Positive, Neutral, or Negative based on tone and language.

- Open-Ended Question : A type of survey question that allows respondents to write their own answers freely.
