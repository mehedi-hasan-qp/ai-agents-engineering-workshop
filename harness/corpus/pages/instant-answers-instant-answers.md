How to launch Instant Answers?

Go to: instantanswers.questionpro.com

By default, the Survey Name is: Instant Answers - Survey 01 (01 being the first survey user is launching from the tool. It continues to increase by default as more surveys are launched).

Next, type in the question you would like to ask. One can always switch between single select and select many question type. Post which you can select the target country in the dropdown and number of respondents to be reached.

Please note that the maximum number of answer options that can be added is 20 for now.

Once launched, you will be displayed with a success message and will be redirected to the Surveys page as shown below:

Here, you can view the survey results in a chart by clicking on the survey name hyperlink. One can also download the survey results in a pdf format by clicking on the download button on the top left corner of the pop-up. Please refer to the below screen:
