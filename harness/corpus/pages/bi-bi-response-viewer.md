## BI-Response-Viewer

1. Introduction

The BI-Response-Viewer widget allows users to view individual-level survey responses directly within a dashboard environment. It provides a clean, scrollable, and paginated interface to inspect detailed response data without having to export or switch contexts.

Purpose and Benefits:

- Enables analysts and stakeholders to view raw survey data inline with visual analytics.

- Supports quick diagnostics, audit trails, and verbatim review for text responses.

- Ideal for QA, storytelling, and deep dives into outlier or thematic segments.

1. Core Functionality

- Dashboard Integration: Add the widget as a visual block to any BI dashboard layout.

- Response Pagination: Navigate through all responses page by page.

- Horizontal Scroll: Easily scroll across all survey questions from left to right.

- Timestamp Display: View response time and date per entry, supporting audit needs.

- Response Filtering: Filter the Response Viewer data by applying column-level filters on available Questions and BI variables.

1. Step By Step Guide

- Step 1: Create dashboard – To create response view widget create a new dashboard or in an existing one, go to Step 6.

- Step 2: Select blank dashboard – Choose a blank dashboard layout as the starting point for adding your response view widget.

- Step 3: Add widget – Click on “Add Widget” to begin inserting response view into your dashboard.

- Step 4: Select advanced widget – User need to select advanced widget to add response view.

- Step 5: Select response view widget – User can select response view (table) and add to dashboard.

- Step 6: Select survey – User need to indicate which survey dataset needs to be added as a widget to the dashboard.

- Step 7a: Right arrow (Page next) – User choose to review the response by moving to the next page in the widget.

- Step 7b: Horizontal scroll – User choose to review all responses and questions in the survey.

- Step 8: Settings > Columns – User can choose columns they would like to add in the response view widget.

Metadata: Choose to display survey metadata in the widget.

- Questions: Choose to display survey questions in the widget.

- System variables: Choose to display system variables in the widget.

- BI variables: Display BI variables mapped to the survey. Coming soon

- Step 9: Response filtering – User can filter the Response Viewer data by applying column-level filters on available Questions and BI variables.

Click the filter icon next to a Question or BI variable column header.

- Select one or more response values to refine the data shown in the widget.

- These filters are temporary and apply only to the current session.

- Filters do not persist across page refreshes or shared dashboards.

Glossary

- Response Viewer: A dashboard component that shows row-level survey response data.

- Pagination: Breaking the data into multiple pages for easy navigation.

- Scroll: Moving horizontally to see all available columns/questions.

- BI Dashboard: A visualization interface used to view, analyze, and interact with data insights.

- Response Filtering: A temporary column-level filter in the Response Viewer used to refine data by selected Question or BI variable responses.
