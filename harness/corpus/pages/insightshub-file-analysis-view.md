## File analysis view

What is file analysis view?

InsightsHub file analysis view is an artificial intelligence driven system that transforms static research uploads into structured insight assets. By automatically generating summaries, extracting critical findings, and applying intelligent tags, it allows you to quickly assess content relevance and leverage existing research more effectively without manual analysis.

How do I upload files for AI analysis?

The system begins analyzing your documents the moment they are added to the repository. Follow these steps to start the process:

- Log in to your InsightsHub account.

- Navigate to the Repository section.

- Select an existing repository or create a new one to house your data.

- Inside the chosen repository, click on Import Data .

- Select and upload your document.

- Once the upload is complete, the system automatically extracts content and begins the analysis.

A progress indicator will show while the summary is being generated. Once finished, you can view the results in the File analysis overlay.

Which file formats are supported for analysis?

The analysis system currently supports the following manual file uploads:

- PDF documents

- DOCX files

- PPTX presentations

- TXT files

Please note that quantitative file formats such as XLS and CSV are not supported in the current version and are planned for a future update. There are also limits on file size and format; the system will display a validation message if your file exceeds these supported limits.

How do I view the AI generated summary?

Every analyzed file includes a comprehensive summary broken down into three specific sections to help you grasp the content at a glance:

- Recap: A high level overview of the document discussion and main themes.

- Details: Key points extracted from the text.

- Suggested next actions: Actionable steps or follow up items derived from the document content.

You can copy this summary for use in other documents or provide feedback on its quality using the built in rating system.

How do I manage insights and tags?

The system identifies critical findings and recommends thematic tags for every document. To manage these assets:

- Review insights: Open the Insights tab to see AI suggestions. You can choose to Accept or Cancel individual suggestions.

- Use intelligent tags: The system automatically applies tags like Consumer Trends or Brand Perception. In the Tags tab, you can view tag groups and click any tag to instantly filter and display all associated insights in real time.

Accepted insights and tags are saved to the repository with a timestamp and author ID to maintain a clear audit trail.

How do I resolve errors during file analysis?

If the system encounters an issue, it will display a user friendly error message such as "Unable to generate summary. Try again or contact support." Common resolutions include:

- Retry: Use the contextual retry options provided in the error message.

- Check file type: Ensure the file is one of the supported formats (PDF, DOCX, PPTX, or TXT).

- Check file size: Verify that the file does not exceed the size limits.
