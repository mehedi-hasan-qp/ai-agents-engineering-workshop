## Create and manage LivePolls

What is the LivePolls unified editor?

LivePolls by QuestionPro is a real-time engagement tool for conducting live polls, quizzes, and trivia. With the unified editor, you no longer have to decide between a poll or a quiz before you start. You can now use a single editor to create a session that consists purely of feedback questions, purely of scored trivia, or a seamless mix of both.

How do I create a new LivePoll?

- Log in to your LivePolls account.

- Select the workspace you want to create the LivePolls in: Personal or Team workspace

- Click the + New LivePoll button to enter the LivePoll editor.

- Choose one of the following methods to build your content:

- Start from scratch: Use this option to manually build your questions on a blank canvas.

- Start with AI: Generate high quality questions automatically by providing your existing notes or textbooks.

- Template: Select a pre-built LivePoll from our template library to save time.

How do I build content in the unified editor?

Customize your LivePoll session using the Add Question sidebar. Choose from various question types to create a poll, a quiz, or a combination of both.

For feedback and polls:

If you want to gather opinions or visualize audience sentiment, choose question types like multiple choice, this or that, livefeed, or word cloud . These questions will display live dynamic charts during your session.

For knowledge testing and quizzes:

If you want to run a competition or test knowledge, choose question types like select answer or true or false . Adding these question types automatically enables the following features:

- Correct answer logic: You can designate one or more options as the right answer.

- Scoring and difficulty: You can assign specific points and difficulty levels to individual questions.

- Leaderboards: Individual leaderboards are automatically enabled as soon as a scored question is added to your session.

How do I manage audience engagement settings?

You can customize how your audience interacts with your LivePoll session by using specific engagement controls, such as:

- Respondent anonymity: When this is activated, the system automatically assigns an alias to all participants. This encourages honest feedback and keeps the environment low pressure.

- Team engagement: You can enable teams to run competitive group trivia and quizzes.

Team mode is currently supported only for select answer and true or false question types. When active, the system tracks both team based and individual leaderboards for these scored questions.

How do I manage results and analytics?

The unified editor ensures that your data is handled correctly even if you use a mix of question types:

- Mixed results integrity: If your session includes both opinion polls and quiz questions, the leaderboard will only calculate points based on the designated quiz questions.

- Live visuals: Poll questions will continue to show live vote distribution charts, while quiz questions will prioritize the leaderboard and correct answer reveals.

FAQ

How do I enable permanent rooms?

Permanent rooms are currently disabled to ensure platform stability during the transition to the unified editor. They are scheduled to return in a future update.

Why can I not use team mode for multiple choice or word cloud questions?

Team mode is currently supported to select answer and true or false question types to ensure accurate scoring and leaderboard functionality.
