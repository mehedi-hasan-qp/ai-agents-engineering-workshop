## Assessment Delegations

Delegation allows admin user, vendors to delegate a part of assessment or complete assessment to another user. It allows user to assign part of assessment applicable to role, department etc. so that accurate response can be captured.

How to enable delegation for portal?

To enable delegation, go to:

- Login>> Assessment

- Select portal for which you want to enable delegation

- Go to security and enable delegation

How can I delegate assessment to user?

Admin user and vendor both can delegate a part of assessment or complete assessment.

For admin user to delegate an assessment, go to:

- Login>> Assessment

- Select portal in which you want to delegate the assessment

- In dashboard page, click on the delegate against a vendor for whom you want to delegate the assessment

- Delegate complete assessment or partially by selecting delegate option against each section

For vendor to delegate an assessment, go to:

- Vendor Login>> Dashboard

- Click on delegate option given against assessment name or sections of assessment to delegate the assessment completely or partially

- Enter the email address of the user to whom you want to delegate the assessment.
