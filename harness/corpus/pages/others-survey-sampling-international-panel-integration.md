## Survey Sampling International (SSI) Panel Integration - How to? (SSI integration)

QuestionPro has the enhanced ability to integrate with External Panel providers.

How to set up integration with SSI?

To set this up go to: Login » Surveys » Edit » Completion
From the Select Finish Option: drop down menu select the SSI option under Panel Integration and Save the changes.

What are the next steps?

Once you save the settings we provide you with the link for the Survey. Please pass on the link to your contact at SSI for testing / distribution. If you have support/sales questions for SSI, please contact them via email at [email protected] or phone 203 567 7200.
SSI will need to pass in the correct variables via corresponding custom variables as per the given link.

What are these three redirect links given to me from my panel provider?

If you've been given three redirect links, you don't need to do anything with them when using QuestionPro. All you need to do is complete the following steps above. Again - there is nothing you need to do with these links.

What other settings are required?

Depending on your requirements you may need to setup Branching and setup Automatic Quota Control for the Survey. For more information please visit the links under Additional References.
