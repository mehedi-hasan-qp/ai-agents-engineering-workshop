## Import External Ticket Data Into Enhanced Closed Loop

The bulk ticket import feature allows you to import external ticket data into your Enhanced Closed Loop account

To import ticket data into your Enhanced Closed Loop Workspace:

Go To: Enhanced Closed Loop » Manage » Bulk Import

Select Workspace Download Import Template to download the template.

Fill data in the downloaded template file with proper format as per suggestion given in the template columns for individual questions and save it.

Choose the saved template file and click Upload button.
